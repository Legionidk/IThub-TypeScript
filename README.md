# Single Responsibility Principle

Каждый класс отвечает строго за одну задачу:

- `FileReader` - читает файл и возвращает массив его строк (`string[]`)
- `ShapesParser` - принимает на вход массив строк лога от `FileReader` и выделяет главную информацию из каждой строки
    - В нашем случае возвращает `ShapeRecord[]`, но интерфейс `IParser` позволяет использовать любой кастомный объект благодаря `<T>`
- `ColorsCollector` - принимает массив от `ShapesParser` и подсчитывает количество цветов в логах, возвращая объект `Map<string, number>`
- `ShapesCollector` - принимает массив от `ShapesParser` и подсчитывает количество фигур в логах, возвращая объект `Map<string, number>`

# Open/Closed principle

Благодаря интерфейсам есть возможность добавить новые парсеры, коллекторы статистики, а также указывать разные источники логов. В будущем можно дописать `IFileReader`, чтобы добавить чтение других форматов.

# Interface Segregation Principle

Интерфейсы маленькие и специализированные, описывающие только свои функции.
